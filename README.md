# Výprava Batoně

**Výprava Batoně** je interaktivní desktopová hra pro děti, která spojuje matematiku, příběh a hru.  
Hráči pomáhají Batonovi překonávat překážky tím, že řeší matematické úlohy.  
Každý chybný krok stojí energii – stejně jako v reálném životě.  
Hra rozvíjí radost z učení, schopnost plánování a práci s chybou.

## Funkce
- Propojení výuky a hraní
- Jednoduché ovládání a přívětivé prostředí pro děti
- Energie jako prvek strategie
- Matematické úlohy v příběhovém kontextu


## Technologie
